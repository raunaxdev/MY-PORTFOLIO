# Raunak Kumar Jha - Digital Portfolio

A modern, responsive, and professional digital portfolio website built to showcase my projects, skills, certificates, coding journey, achievements, resume, and social media links.

## 🚀 Live Demo

[View Portfolio](YOUR_PORTFOLIO_LINK_HERE)

## 👨‍💻 About

This portfolio represents my journey as a BCA student and aspiring full stack developer. It includes my technical skills, real-world projects, certificates, goals, feedback system, and an admin dashboard to manage portfolio content dynamically.

## ✨ Features

* Modern responsive UI
* Animated hero section
* Project showcase
* Project screenshot support
* Certificates section
* Certificate image preview
* Skills section
* Resume download button
* Social media links
* Feedback form
* Admin dashboard
* Supabase authentication
* Supabase database integration
* Supabase storage for images
* Mobile-friendly design
